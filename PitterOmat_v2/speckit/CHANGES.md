# CHANGES (v2 gegenüber v1)

- **Displays:** von 8 → **12**; inaktive zeigen **Logo** statt Menüs.  
- **Steuerung:** **Player 1** ist UI‑Master (Touch); andere zeigen Sitzplätze/Logo bis Start.  
- **Kommunikation:** nur **WiFi** zwischen ESPs (kein ESP‑NOW). **RS‑485** nur ESP↔Mega.  
- **UI:** **manuell** in EEZ (dynamische UI entfernt).  
- **Spielauswahl:** **„LichtLoser“** einziges Spiel (Modus „Standard“). JSON/SD‑Spiele: Non‑Goal.  
- **Joker:** 5‑Spieler‑Sonderfall, **Spiel‑LED‑Gruppe 2**, Farbwahl Gold/Regenbogen.  
- **Ready‑Screen & Highscore:** entfernt.  
- **Idle:** LED‑Effekte + Timeout + optional Energiesparer.  
- **Helligkeit:** globales LED‑Cap **55 %**; getrennte Slider Spiel/Grenze.  
- **Netzwerk/Updates/Cloud/OTA/Hash:** Non‑Goals; nur Platzhalter/Variablen.
